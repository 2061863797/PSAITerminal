主题
    about_PSAITerminal

简短说明
    在官方 PowerShell 中使用本地 AI 问答、命令建议和多步骤 Agent。

平台
    支持 Windows PowerShell 5.1（x64/x86）和 Windows 上的 PowerShell 7.4 及以上版本。
    Linux 和 macOS 不受支持，相关实现已从发布代码中移除。

开始使用
    输入 ai 并按 Enter，新增并选择模型。

    输入 ai <问题> 并按 Enter，可在任何模式下明确询问 AI。

模式
    Off   Enter 始终按 PowerShell 执行。
    AI    普通输入全部先交给 AI，包括合法 Shell 命令和不完整代码。
    Auto  明确的命令先执行；无法运行时把原始输入交给 AI。

输入与会话
    Enter/F2 将不完整 AI 输入只提交一次并保留原文；Auto/Off/F3 保留原生续行，
    Shift+Enter 保留多行编辑。明确咨询不携带工具、不创建 Run，Auto 模糊输入在本地澄清。
    每个终端使用独立会话；导入、新建和切换会话不改写共享配置，显式配置修改仍检查修订号。

界面语言
    默认界面语言为 English。输入 ai，选择“语言 / Language”即可切换 English 或简体中文；语言选择会持久化。

快捷键
    F2    先输入内容，不按 Enter，按 F2 强制交给 AI。
    F3    先输入命令，不按 Enter，按 F3 强制按 PowerShell 执行。
    F6    切换 Off、AI、Auto。
    F7    解释最近一次命令及其结果。

    部分笔记本需要同时按 Fn。运行 Get-PSAIIntegrationStatus 可以确认快捷键是否启用。

诊断
    Test-PSAIConfiguration
        检查安装位置、配置、凭据、接口地址、PSReadLine 和快捷键。

    Test-PSAIConfiguration -Online
        在本地检查之外发送一次最小模型请求。

凭据
    API Key 保存在 Windows Credential Manager，不写入 JSON。
    模块默认请求跨登录会话持久化；受限登录会话返回 1312 时，会安全降级为当前登录会话凭据，
    不会改为明文保存。

常用命令
    Get-PSAIModel
    Get-PSAISession
    Get-PSAIRun
    Set-PSAITerminalMode Off|AI|Auto
    Uninstall-PSAITerminal

安全确认
    AI 生成的目的、预期和副作用可能不准确，请以确认界面显示的完整命令为准。
    高风险命令不支持回车默认执行，并要求第二次明确确认。
    所有风险等级都展示目的、命令、预期、副作用、回滚和本地风险六项。
    批准与命令、说明、计划推进信息和 Run 修订号绑定；内容变化后必须重新批准。
    编辑后撤销批准，禁用工具生成四项新说明；失败显示“无法评估”，只能重新编辑或拒绝。
    回滚内容只是 AI 生成的操作建议；模块不会自动备份、撤销或恢复系统状态。
    命令使用当前用户权限在当前 PowerShell 会话中执行，不是隔离沙箱。

交互可靠性（1.0.4）
    咨询请求不携带工具；待澄清输入只显示本地问题，请重新输入完整需求。
    单步与多步按结构化计划推进，不依赖任务关键词。末步成功直接完成，不追加模型请求。
    普通步骤只显示步骤完成；如需检查产物，计划必须保留验证步骤。F7 仅主动触发时解释。
    Run v2 保存计划、完成条件、步骤角色、执行结果，以及正常执行、清理恢复和重试阶段。
    清理成功回到原步骤，清理失败暂停，等待 ai resume <RunId>。每条清理和重试均需批准，
    且计入最大步骤数；模块不能检测全部副作用，不保证恢复成功。失败不会显示成功完成文案。
    旧的已完成 Run 可以查看；旧的未完成 Run 必须重新规划和批准。结果不确定时先执行
    Resolve-PSAIRun 明确确认是否执行及结果，不能自动重放。

未发布整改
    原生、正文 JSON 和 YAML 提议要求完整说明、计划及完成字段；最多修复一次，首次无效
    计划不会固定到 Run。超过 16384 字符或会被脱敏改写的命令直接拒绝，请使用变量或凭据引用。
    编辑说明仅接受四字段 JSON 对象，允许完整包裹于单个 JSON 代码块；额外文字和工具调用无效。
    Auto 保留本次真实原生退出码，纯 PowerShell 保留此前 LASTEXITCODE 或未定义状态。
    流式单行上限在读取中检查；DACL 失败抛出包含原始 Win32 错误码的异常。

卸载
    两个入口均先验证绝对路径和模块/数据归属，拒绝受保护目录与重解析点。
    Force 仍遵守 WhatIf 和显式 Confirm；删除失败报错。普通卸载保留凭据。
    PurgeUserData 只删除已确认的配置、会话、Run 文件及配置模型名称对应的
    PSAITerminal/Model/<名称> 凭据，保留无关文件和凭据。凭据失败时保留配置供重试。
    CredentialsPurged 在未请求 Purge 时为 false，全部目标已删除或不存在时才为 true。
    Windows 可能占用当前宿主加载的 DLL。内置卸载若报文件删除失败，关闭占用终端，
    再从 pwsh -NoProfile 或 powershell -NoProfile 运行独立脚本。凭据子进程退出后才删除 DLL。

说明
    PSAITerminal 不预置模型，首次安装默认为 Off，也不会自动联网。
    当前包未做 Authenticode 代码签名；手动安装时应核对官方 Release 提供的 SHA-256。
    API Key 不写入 JSON 配置。Windows 使用 Credential Manager；
    密钥库不可用时可显式选择仅当前会话使用。
